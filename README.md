## 一分钟上手（最简单，零风险）

1. 双击打开 `dist\佐拉口琴谱伴.exe`
2. 左侧已经自动载入「小星星」示例
3. 模式选 **手动辅助**（默认）
4. 点 **▶ 开始演奏**（或按 **F5**），下方会大字显示当前要按的键（`z`–`m`；半音显示为 `中键+字母`）
5. 进游戏，掏出佐拉送的口琴道具，按提示自己按 `z x c v b n m`；遇到 ♯/♭ 时 **按住鼠标中键** 再按对应字母
6. 点 **⏹ 停止** 或按 **F6** 随时中断

> 这就是最安全的使用方式：**脚本只显示提示，按键全是你自己来，不会触发反作弊。**

## 想直接自动吹？两种高级玩法

### 方式一：鼠标宏手写教程（中风险）

任意品牌鼠标宏软件均可（不必再依赖 G HUB Lua）：

1. 模式选 **鼠标宏教程**
2. 点主按钮 **📤 导出宏教程 MD**
3. 打开生成的 `.md`：按键位表、逐音动作表与伪代码，在驱动里手写宏
4. 普通音 = 按下字母；半音 = 中键按下 → 字母 → 抬起；按 BPM 填延迟
5. 绑到侧键；安全区先呼出口琴界面再触发

> ⚠ 风险：键鼠宏 / 驱动回放仍可能被 ACE 监控。**建议只在单人/安全区用。** 旧版 G HUB Lua 导出已弃用。

### 方式二：自动注入（高风险）

程序直接模拟你按键盘鼠标：

1. 模式选 **自动注入**（首次会弹风险确认窗）
2. 游戏内先呼出口琴界面，保持游戏窗口在最前
3. 点 **▶ 开始演奏** 或按 **F5**，脚本自动按 `z`–`m`；半音时按住中键

> ⚠ 风险极高：这属游戏明令禁止的自动化，查实封号十年 + 机器码永久封禁，换号无效。**强烈不建议用，本工具默认隐藏此功能风险。**

## 简谱怎么写？

用空格分开每个音，一行写几句都行：

| 写法 | 意思 |
| --- | --- |
| `1 2 3 4 5 6 7` | do re mi fa sol la ti（演奏键 `z x c v b n m`） |
| `#1` `#3` | 升（演奏：按住中键 + 字母） |
| `b3` `b6` | 降（演奏：按住中键 + 字母） |
| `5 - -` | 这个音吹 3 拍（`-` 延长一拍） |
| `1.` | 附点（吹 1.5 拍） |
| `1_` | 八分音符（吹半拍） |
| `0` | 休止（停一拍） |
| `\|` | 小节线（看着舒服，不影响演奏） |
| `// 注释` | 备注，不影响演奏 |
| `@bpm 100` | 曲子的速度（每分钟 100 拍） |

**网上常见的简谱也能转**：把 `1155665`、`[1]`（高八度）、`1.`（点八度）、`♯1` 这种格式粘贴到「转换简谱」里，一键转成上面这种格式。

**让 AI 帮你写谱**：演奏页有「AI 简谱提示词」面板，点右上角 **复制**，粘贴给 ChatGPT / Claude 等，再附上歌名或旋律即可。

## 常见问题

**Q: 为什么有的音吹出来不对？**
A: 口琴只有基础音区（约一个半八度），带 `^`（高八度）或 `,`（低八度）的音符会吹成基础音区，这是道具本身限制。底部警告区会标出超范围音符，你需要换调或改编。

**Q: B 模式按了没反应？**
A: 检查游戏窗口是否在最前；若还不行，到「设置」把输入后端改成 `keyboard_ctypes`，并以管理员身份运行 exe。

**Q: 曲子太长，想慢点/快点？**
A: 「设置」里调 BPM，或在曲谱开头写 `@bpm 120`。

**Q: 怎么把写好的曲子分享给别人？**
A: 点「💾 保存曲谱」存成 `.txt` 发给别人，对方点「📂 载入曲谱」即可。

**Q: 热键和游戏冲突怎么办？**
A: 默认 F5/F6 避开了演奏键与 WASD；可到「设置 → 全局热键」改成别的功能键后点「应用热键」。

## 反作弊风险（必读）

三角洲行动用 ACE 内核级反作弊，**强制启动、无法关闭**。官方明令禁止 Python/AutoHotkey 类自动按键脚本，查实即 **封号十年 + 机器码永久封禁**。

| 模式 | 风险 | 原理 |
| --- | --- | --- |
| 手动辅助（C） | **零** | 只显示提示，你自己按键 |
| 鼠标宏教程（E） | **中** | 导出 MD 教你手写驱动宏，宏本身仍可能被监控 |
| 自动注入（B） | **高** | Python 直接注入键鼠，明令禁止 |

**强烈建议只用手动辅助模式。** 本工具不读写游戏内存、不绕过反作弊，仅供彩蛋娱乐，一切后果自负。

## 项目结构

```
harmonica/
  main.py              入口
  config.py            配置保存（键位 / 热键 / BPM）
  score_parser.py      简谱解析 + 音域检查
  score_convert.py     简谱格式转换（连写/括号/点八度 → 本工具记法）
  humanizer.py         时序抖动（降低检测概率）
  input_backend.py     键鼠注入后端（pydirectinput / keyboard / null）
  dispatcher.py        播放调度（B 注入 / C 提示）
  macro_md_exporter.py 导出鼠标宏 Markdown 教程
  ghub_exporter.py     [已弃用] 转发到 macro_md_exporter
  gui.py               界面（customtkinter 暗色主题）
  scores/              示例曲谱（小星星/茉莉花/天空之城）
build.bat              一键打包 exe
requirements.txt       依赖清单
```

## 开发

```powershell
pip install -r requirements.txt
python -m harmonica          # 运行
.\build.bat                  # 打包 exe
```

配置文件在 `%APPDATA%\佐拉口琴谱伴\settings.json`，异常日志在 `error.log`。
